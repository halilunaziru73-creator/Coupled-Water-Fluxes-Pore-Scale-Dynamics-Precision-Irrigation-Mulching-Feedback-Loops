**What 1.1.0 adds to 1.0:** the crop library and staple, cash and vegetable crops; full Daisy outputs and year-by-year layers; design runs on request with value inputs, design charts and the soil-water film of every design; weather import and online weather with forecast in every design; the guided field sketch; the field on the map (Sentinel-2 indices, image analysis of the satellite photo, water sources and irrigation systems, the season of the field, variable-rate irrigation simulated zone by zone, ephemeral gullies and soil loss, report at a chosen dpi); planting advice; the complete Trigger law and Soil hydraulic drivers dashboards; and the manual of 525 pages.

**Build either version** (Windows, needs Node.js LTS): open the inner `SWAFL_Desktop` folder of that version in VS Code and run `npm.cmd install` then `npm.cmd run get-app`.
