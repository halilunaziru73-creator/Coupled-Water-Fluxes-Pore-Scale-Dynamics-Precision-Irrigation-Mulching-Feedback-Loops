# `\texorpdfstring{\chapicon{partpurple}{⚖}}{}`{=latex}The best combinations {#daisy-combos}

Start from the Daisy reference offers 43 combinations of factors that the Daisy reference manual makes worth comparing. Each is shown as it opens in the Experiments tab, with the reason it is offered and the place of the reference manual where its parameters are described.
