\dykband{EXERCISES IN SWAFL}
{\small Open SWAFL (desktop or online) with the benchmark project. The chapter of the \href{https://github.com/halilunaziru73-creator/Coupled-Water-Fluxes-Pore-Scale-Dynamics-Precision-Irrigation-Mulching-Feedback-Loops/raw/main/Software/v1.1.0/SWAFL_Desktop/docs/manual_v1.1.0/SWAFL_Manual_v1.1.0.pdf}{SWAFL manual} that explains each task is given in brackets; record your values in a table and compare them with what is expected (\emph{Check}).}\par\vspace{3pt}
\begin{exlist}
\item {\color{khblue}[Manual, Chapter 5]} Run the same field balance with Engine 1 and with Engine 2. Compare the drainage and the evaporation and explain the difference.\par\noindent{\small\itshape Check: the two engines agree closely on annual totals.}
\item {\color{khblue}[Manual, Chapter 14]} Read the \emph{Design} tab of the Dashboard for the drip layer and identify which numbers come from which equation.\par\noindent{\small\itshape Check: each number names its equation.}
\item {\color{khblue}[Manual, Chapter 18]} Run a design and watch the value window of an input. Change the input through its full range and record the result.\par\noindent{\small\itshape Check: the result changes smoothly with the input.}
\item {\color{khblue}[Manual, Chapter 22]} Project the seasons after the last simulated one and comment on the reliability of the projection.\par\noindent{\small\itshape Check: the projection carries the uncertainty of the record.}
\end{exlist}
