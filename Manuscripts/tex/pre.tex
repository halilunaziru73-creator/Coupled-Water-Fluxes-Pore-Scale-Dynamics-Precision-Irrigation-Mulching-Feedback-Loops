\newcommand{\dataavail}{%
\textbf{Data.} The complete Daisy ensemble outputs (all 10\,190 runs, raw and derived) are archived on Zenodo, \doihl{10.5281/zenodo.23043626}. The raw run table used here, and a linked list of every data file used, are in the \datalink{} folder of the project repository (\url{\dataurl}).
\par\smallskip\textbf{Code.} The analysis and figure scripts are in the \codelink{} folder (\url{\codeurl}). The folder \texttt{Manuscripts/reproducibility} is a self-contained package: pinned software versions (Python 3.13.16, NumPy 2.5.3, SciPy 1.18.1, pandas 3.0.5, scikit-learn 1.9.1, statsmodels 0.15.0, Matplotlib 3.11.2, Pillow 12.3.0), fixed random seeds in every stochastic step, SHA-256 checksums, and one command (\texttt{run\_all.sh}) that regenerates all results and figures from the ensemble and then compares every regenerated value with the archived result and with the headline numbers printed in the manuscript. Each table and figure names the script that produced it (Appendix~\ref{app:repro}). Daisy itself was not re-run for this package, no field measurements are used, and small intermediate arrays used only by figures are archived rather than regenerated; these limits are listed in \texttt{README\_REPRODUCE.md}.}
